# A Todo app to study Svelte and Firebase

## Some nice tools used for development

### bun

Kind of a npm but better.

### degit

Used to copy project structure from a boilerplate repository.

### rxfire firebase

Libs to use Firebase. rxfire purpose is to simplify async streams from Firebase.

### rxjs

Library to programming using Observables, to make it ease to compose asynchronous or callback-based code.
